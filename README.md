# FAQ-бот репетиции — hack-cd506aa9-lalalallala

Терминальный чат, который отвечает на 5 частых вопросов про репетицию хакатона:
время, состав команды, треки, сдача, призы. Python 3, только стандартная библиотека,
ставить ничего не нужно.

## Как запустить

```bash
python3 faq_bot.py                      # чат в терминале
python3 faq_bot.py "во сколько старт?"   # один вопрос — один ответ
```

В чате: `/help` — список всех вопросов, `выход` (или `exit`, Ctrl-D) — закончить.

## Пример

```
FAQ-бот репетиции. Задайте вопрос, /help — список тем, «выход» — закончить.
вы  > а можно одному, без команды?
бот > Команда — от 1 до 5 человек. Одному можно, но удобнее втроём: кто-то берёт код,
      кто-то демо и презентацию. Состав команды можно менять до старта задач.
вы  > будет ли еда
бот > Не знаю. Я отвечаю только про репетицию: время, команду, трек, сдачу и призы.
```

## Как устроено

Никакого RAG — совпадение по ключевым словам. Вопрос приводится к нижнему регистру,
`ё` → `е`, выкидывается пунктуация и стоп-слова, а слова обрезаются до 5 символов,
чтобы «команды», «командой» и «команде» считались одним словом. Для каждой записи
из `faq.txt` считается доля слов вопроса, которые в ней нашлись; синонимы из строки
`K:` дают небольшой бонус. Побеждает лучшая запись, но если её оценка ниже порога
`MIN_SCORE = 0.34` — бот честно отвечает «не знаю».

## Как добавить вопрос

Открыть `faq.txt` и дописать блок (записи разделяются пустой строкой):

```
Q: Будет ли еда на площадке?
A: Обед в 13:00, кофе и печенье весь день.
K: еда, обед, кофе, перекус, покормят
```

Код трогать не нужно — `K:` нужна только для синонимов, которых нет в самом вопросе.

## Тесты

```bash
python3 -m unittest test_faq_bot.py -v
```

Проверяют, что база читается, что 5 вопросов «своими словами» попадают в нужные записи
и что посторонние вопросы получают «не знаю».

## Что получилось

Работающий чат на 5 вопросов, база в текстовом файле, 4 теста, запуск одной командой.
За рамками осталось намеренно: морфология через библиотеку, опечатки, синонимы через
эмбеддинги — для пяти известных вопросов ключевых слов достаточно.
